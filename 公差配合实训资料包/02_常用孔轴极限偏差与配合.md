# 02 常用孔/轴极限偏差与配合（GB/T 1800.1-2020 / GB/T 1800.2-2020）

> **本地化数据**：依据 **GB/T 1800.1-2020**（公差、偏差和配合的基础）与 **GB/T 1800.2-2020**（标准公差带代号和孔、轴的极限偏差表）整理。
> 单位：**表中偏差数值为 μm**，换算成 mm 时除以 1000（表中 `+25` 即 `+0.025 mm`）。
> ⚠️ **重要**：基本偏差表使用的是**细分尺寸段**（>10–14、>14–18、>18–24、>24–30、>30–40、>40–50、>50–65、>65–80 …），**与标准公差表用的粗尺寸段不同**。本实训所有尺寸（14/15/17/20/30/35/40/68）都落在上面这些细分段里，且除下文标「分档」者外，同一粗段内数值相同。
> 机器可读版：`数据表_孔轴极限偏差.csv`、`数据表_本实训尺寸极限偏差.csv`

## 一、基本偏差换算规则（GB/T 1800.1-2020）

| 代号 | 规则 | 说明 |
|---|---|---|
| **A ~ H（孔）** | **EI = −es**（同名轴） | 例：g6 的 es = −6 → G7 的 EI = +6 |
| **a ~ h（轴）** | 直接查表（均为 **es**） | h 的 es = 0 |
| **JS / js** | ES = +IT/2，EI = −IT/2 | 对称分布，故写 ±IT/2 |
| **J、K、M、N（孔）** | **ES = −ei + Δ**，Δ = IT_n − IT_(n−1)；适用 ≤IT8（>3–500 mm） | 等级比 IT8 粗时 ES = −ei |
| **P ~ ZC（孔）** | **ES = −ei + Δ**；适用 ≤IT7 | 等级比 IT7 粗时 ES = −ei |
| **N 特例** | >3–500 mm 且等级 >IT8 时 **ES = 0** | |

**Δ 值（μm，本实训用到的段）：**

| 尺寸段 | IT7−IT6 | IT8−IT7 | IT9−IT8 |
|---|---|---|---|
| >10–18 | 7 | 9 | 16 |
| >18–30 | 8 | 12 | 19 |
| >30–50 | 9 | 14 | 23 |
| >50–80 | 11 | 16 | 28 |

> 这个 Δ 的存在意义：保证**同名配合等价**（例如 H7/k6 与 K7/h6 的极限间隙/过盈完全相同）。本文件第 4 节用它做了自检。

## 七、数据可信度与存疑清单（务必照实写进报告的"数据来源"）

**已交叉验证的**

1. 标准公差 IT 值：三源一致（含 IT12–IT18 = IT7–IT13 ×10 的内部规律）。
2. 轴 d/e/f/g/h/m/n/p 与孔 D/E/F/G/H：多源一致。
3. **φ15g7 = −0.006/−0.024**：与实训指导书 P15 原文给出的 `Φ15 −0.006/−0.024` 完全一致（这是最强的实测校验点）。
4. K7 / M7 / N7 / P7：既与标准表的直读值一致，又能由 `ES = −ei + Δ` 反算闭合，且满足同名配合等价。

**曾出过、已修正的错**

- 一度把 **n 的数值当成 k 的数值**（误得 φ17k6 = +0.023/+0.012、φ40k6 = +0.034/+0.018）。正确值为 **φ17k6 = +0.012/+0.001、φ40k6 = +0.018/+0.002**。
  识别方法：k < m < n < p < r < s < u，ei 必须递增；若 k 比 m 大就是错了。**本文件第 2~5 节已按正确值重算。**

**存疑 / 未取得官方原文（不要当作定论）**

1. GB/T 1800.1-2020 与 GB/T 1800.2-2020 都是**采标标准**（MOD ISO 286-1/2:2010），国家标准全文公开系统**不提供在线阅读**，故以上数值为多来源交叉比对结果，**未与官方 PDF 逐格核验**；正式报告建议与教材附表或标准正式文本复核一次。
2. 轴 **j**（j5/j6/j7/j8）中英来源在 18 mm 以上差一档，**存疑**——本实训不需要 j，未采用。
3. 孔 **J6/J7/J8**、孔 **R6/R7**、孔 **U6/U7** 在部分尺寸段为推算值而非直接抄录，**存疑**——本实训未采用。
4. ≤3 mm 时 K/M/N 是否加 Δ 与 >3 mm 规则不同，未能与原文确认——本实训最小尺寸为 14 mm，不受影响。
