## 二、数据可信度（务必先看，报告里要照实写）

| 数据 | 可信度 | 说明 |
|---|---|---|
| 国标**状态/日期/替代关系** | ✅ 官方平台核实 | 直接来自国家标准全文公开系统 openstd.samr.gov.cn |
| 标准公差 **IT 值** | ✅ 高 | 多源一致；且被一本教材的"表 2-1（明确标注**摘自 GB/T 1800.1—2020**）"逐行匹配；并与指导书 P15 给出的 `Φ15 −0.006/−0.024`（T = 0.018 = IT7）自洽 |
| 基本偏差 **d/e/f/g/h/k/m/n/p**、孔 **D/E/F/G/H/K7/M7/N7/P7** | ✅ 高 | 多源一致 + 用"同名配合等价"（H7/k6 ↔ K7/h6 的 X_max/Y_max 完全相同）闭合验证；且被教材例题逐点印证：φ30g6 的 es = −7、φ35k6 的 ei = +2（φ35H7/k6 的 X_max = 23 μm）、φ25r6 的 ei = +28、φ45P8/P6 的 ES = −26/−21 |
| 基本偏差 **r/s/u** | ⚠️ 待核 | 细分段内有分档，本文档只给了整理值；**本实训不用** |
| **安全裕度 A / u₁** | ⚠️ 单一来源（自洽校验通过） | 来自可全文读取的课件文本；已通过 A = T/10、T 与 IT 表一致、u₁ ≈ 0.9u 三项自洽校验 |
| **量规公差 T / 位置要素 Z** | ✅ **已补齐（双通道核对）** | 取自一本教材的表 2-23（IT6–IT9 全表）；① 已渲染成图**逐格视觉复核**；② 教材自带例题 φ25H8（T = 3.4、Z = 5.0）与 φ45f8（T = 4.0、Z = 6.0）反算完全闭合。⚠️ 原文 IT6/>315–400 的 Z 印成"4"，判为笔误，按规律记 6.0（本实训不用该档） |
| GB/T 3177-2009 的 **IT12–IT18** A/u₁ | ❌ 未取得 | 一般公差尺寸按不内缩（A = 0）处理，本实训不受影响 |

> **一句话**：IT 值、常用孔轴偏差、量规 T/Z 现在都可以放心用；安全裕度 A 建议再对一次教材原文。

## 三、下一步（数据输入）建议流程

> ✅ **已完成**：实测数据已录入 `10`，计算结果与结论已成文于 `11`。下面保留流程供复核。

1. **打印/打开 `10_第一单元_数据录入表.md`** —— 每张表都已按指导书报告单的字段排好。
2. 先做 **表 4-1**（游标卡尺 + 外径千分尺各测 Φ15 同一部位 5 次），算平均值、变化量，用验收极限 14.9778 ~ 14.9922 判定。
3. 依次做 **项目一~项目四**（每处测 3 次），实测值填进表 → 算平均值 → 用"验收极限"判合格。
4. **项目五**：T、Z 已查出并算出通规/止规尺寸（φ35H7 通规 φ35(+0.0055/+0.0025)、止规 φ35(+0.025/+0.022)），直接实测比对；想自己推一遍就看 `03` 号文件 2.2 的公式。
5. 每张表的"与配合零件的实用性结论"：写清楚该处的**配合性质（间隙/过渡/过盈）**、对减速机功能的影响、以及你选用该配合公差带的理由。
6. 需要程序化处理时，直接读 `数据表_*.csv`。

## 四、三条附加提醒

1. **配合代号是我方建议值，不是图纸原值**。本次已逐张核对了附图：装配图和零件图上**绝大多数被测尺寸没有标注公差代号**（只有蜗轮轴两端 φ14 标了 `0/−0.018`）。按指导书 P10「实训前任务」，**给有互换性要求的表面确定并标注公差**正是实训要学生做的事，所以 `10` 号文件里的 `φ68h6`、`φ40H7`、`φ17k6` 等属于**依据现行国标的推荐设计**，请与指导教师确认后定稿。
2. **浏览器技能本次未能使用**。`browser-skill` 依赖本机 `bsk` 守护进程，本次它因沙箱与自动模式限制（日志目录拒绝访问、需要工作区外的持久化权限）没有启动成功。查证改用**直连检索官方平台**完成，结论等价可复核。若需要在浏览器里看官方全文预览页，请先在独立终端执行：

