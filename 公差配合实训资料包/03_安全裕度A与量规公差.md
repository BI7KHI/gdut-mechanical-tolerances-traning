**验收原则**：只接收位于规定尺寸极限之内的工件；**允许误废，不允许误收**。标准温度 20 ℃。

## 1.2 验收极限的两种方案

**（1）内缩方案**（配合尺寸、高公差等级尺寸用）

- 孔：上验收极限 = **LMS − A**；下验收极限 = **MMS + A**
- 轴：上验收极限 = **MMS − A**；下验收极限 = **LMS + A**

写成指导书 P16 的偏差形式（以孔为例）：

```
ES − A ≥ Ea ≥ EI + A
```

| 符号 | 含义 |
|---|---|
| ES / EI | 孔的**上/下极限偏差**（轴写 es / ei） |
| A | **安全裕度**，按工件公差 T 查表，本表恰为 **T/10** |
| Ea | 实际（测量得到的）尺寸，须落在上下验收极限之间 |

> 国标习惯**大写 ES/EI 表示孔**、**小写 es/ei 表示轴**；指导书写的 `Es/Ei` 属简写。

**（2）不内缩方案**：A = 0，验收极限 = MMS 与 LMS 本身。用于**非配合和一般公差**尺寸。

**怎么选：** 遵守包容要求 / 公差等级高的尺寸→内缩；非配合、一般公差→不内缩；**Cp ≥ 1** 可不内缩（但包容要求的最大实体一边仍内缩）；偏态分布可只内缩偏向的一边。

## 2.2 量规公差带的布置与计算式

| 项目 | 规定 |
|---|---|
| 通规（**T**）公称尺寸 | = 被检工件的**最大实体尺寸 MMS**（孔 MMS = EI，轴 MMS = es） |
| 止规（**Z**）公称尺寸 | = 被检工件的**最小实体尺寸 LMS**（孔 LMS = ES，轴 LMS = ei） |
| 通规 | 有**制造公差 T** ＋ **磨损极限**；**通规公差带中心内缩一个 Z 值**，预留磨损量，**磨损极限即工件 MMS** |
| 止规 | **只有制造公差 T，不留磨损储量**（很少通过工件）；**校对量规也不留磨损储量** |
| 总原则 | **量规公差带不得超越被检工件的公差带** |

**计算公式（按"偏差"算最不容易错）**

孔用塞规（检验孔）：

```
通规  上偏差 = EI + Z + T/2
      下偏差 = EI + Z − T/2
      磨损极限（尺寸）= 工件 MMS（即 EI 对应尺寸）
止规  上偏差 = ES
      下偏差 = ES − T
```

轴用卡规/环规（检验轴）：

```
通规  上偏差 = es − Z + T/2
      下偏差 = es − Z − T/2
      磨损极限（尺寸）= 工件 MMS（即 es 对应尺寸）
止规  上偏差 = ei + T
      下偏差 = ei
```

> 这组式子是**量规公差带中心相对工件 MMS 内缩 Z** 的直接展开，与教材例题逐位吻合（见 2.6）。

## 2.4 校对量规（只用于轴用量规）

校对量规公差 **Tp = 工作量规制造公差 T 的 50%**。

| 代号 | 名称 | 判据 |

| **TT** | 校通—通 | 检验轴用**通规**；通过 → 合格 |

## 2.6 教材自带例题（可当模板照抄格式）

**例 A：检验孔 φ25H8（EI = 0，ES = +0.033）**

1. 查表 2-23：被检孔 IT8、尺寸段 >18–30 → **T = 0.0034 mm，Z = 0.005 mm**
2. 通规：上偏差 = EI + Z + T/2 = 0 + 0.005 + 0.0017 = **+0.0067**；下偏差 = 0 + 0.005 − 0.0017 = **+0.0033**；磨损极限 = EI → 尺寸 **25 mm**
3. 止规：上偏差 = ES = **+0.033**；下偏差 = ES − T = 0.033 − 0.0034 = **+0.0296**
4. 结论：塞规通规尺寸 **φ25(+0.0067/+0.0033)**，止规尺寸 **φ25(+0.0330/+0.0296)**

**例 B：检验轴 φ45f8（es = −0.025，ei = −0.064）**

1. 查表：被检轴 IT8、尺寸段 >30–50 → **T = 0.004 mm，Z = 0.006 mm**
2. 通规：上偏差 = es − Z + T/2 = −0.025 − 0.006 + 0.002 = **−0.029**；下偏差 = −0.025 − 0.006 − 0.002 = **−0.033**；磨损极限尺寸 = 44.975 mm
3. 止规：上偏差 = ei + T = −0.064 + 0.004 = **−0.060**；下偏差 = ei = **−0.064**

> 这两个例题与 2.3 表格数值、与 2.2 公式**互相闭合**，是本表可信度的直接证据。

### （C）端盖定心孔 φ68H7

- 被检孔：EI = 0，ES = +0.030（IT7，尺寸段 >50–80）
- 查表：**T = 3.6 μm = 0.0036 mm，Z = 4.6 μm = 0.0046 mm**
- **通规**：上偏差 = 0 + 0.0046 + 0.0018 = **+0.0064**；下偏差 = 0 + 0.0046 − 0.0018 = **+0.0028**；磨损极限尺寸 = **68.000**
  → 通规尺寸 **φ68(+0.0064/+0.0028)**
- **止规**：上偏差 = **+0.030**；下偏差 = 0.030 − 0.0036 = **+0.0264**
  → 止规尺寸 **φ68(+0.030/+0.0264)**
- 量规形位公差 = 50% × 0.0036 = **0.0018 mm**；Ra ≤ 0.08 μm

> 报告里记得写：为什么通规有磨损极限而止规没有；为什么量规公差带必须内缩（不内缩就会把不合格件误收）；Z 的作用是"预留磨损储量"。另外可指出本项目检验的是孔，故**不涉及 TT/ZT/TS 校对量规**。
