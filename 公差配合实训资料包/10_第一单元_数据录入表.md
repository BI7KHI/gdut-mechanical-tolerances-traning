## 录入约定（先读这一节）


| 项         | 约定                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------------- |
| 单位       | 一律**mm**，表头不再重复写单位                                                                                    |
| 有效位数   | 游标卡尺（0.02）记到**0.02 的整数倍**，如 `68.00`；外径千分尺/内径千分表（0.001/0.01）记到 **0.001**，如 `17.012` |
| 符号       | 偏差、间隙、过盈**必须带正负号**（+0.025 / −0.018）                                                              |
| 空值       | 未测的留空，**不要写 0**（0 是有效数据）                                                                          |
| 每点测次   | 指导书 P11 要求"每个测量应重复 3–5 遍"；报告单给 3 列，表 4-1 给 5 列                                            |

| 判定       | 按 GB/T 3177-2009 内缩验收极限：`Es − A ≥ Ea ≥ Ei + A`；A 见 `03` 号文件                                       |
| 建议值标注 | 带 〔建议〕的配合代号是**依据现行国标推导的推荐值**，图纸上并未标注，需与教师/图纸确认后再定稿                    |

## 八、报告填写顺序（建议流程）

1. 读 `00_国标查证与依据.md`，把"依据标准"抄进报告封面页。
2. 查 `01` / `02`，把每个被测尺寸换算成**极限尺寸**，填进各表的"图纸极限尺寸"列（已预填建议值，请核对）。
3. 到实验台实测 3 遍，填"实测值"列 → 算平均值。
4. 查 `03` 的 A 值，算验收极限，判合格（**注意：判合格要用验收极限，不是直接用极限尺寸**）。
5. 写"实用性结论"：这一处的配合性质（间隙/过渡/过盈）、对减速机功能的影响（传动精度、轴承游隙、密封、装拆）。
6. 项目五按 GB/T 1957-2006 算 T、Z 并检验量规实物。
